# Contribution Guidelines

Thanks for helping improve **Awesome AI Competitions**!

## Adding an entry

- Make sure the resource is actually about AI / ML / data science competitions, hackathons or challenges.
- Search the list first to avoid duplicates.
- Add one entry per pull request when possible, with a clear title, e.g. `Add Example Platform`.
- Use the format: `- [Name](https://link) - Short description ending with a period.`
- Keep descriptions short, neutral and non-promotional.
- Put the entry in the most relevant section, keeping the existing order.
- Link to the official site, and make sure the link works.

## Updating or removing entries

- Open a pull request if a link is dead, a platform has shut down, or a description is out of date.
- Issues are welcome for suggestions and discussion.

By contributing, you agree that your contributions are released under [CC0 1.0](LICENSE).
